A platform for university students to find notes and study partners.

## ✨ Features
- Students can post requests for a study partner
- Students can search for and share notes
- Contact other students directly
- (aur features jo tumne banaye hain wo yahan likho)

## 🛠️ Tech Stack
React, Node.js, Express.js, MongoDB

## ⚙️ Setup
1. `git clone <repo-link>`
2. `cd Uni-Zone`
3. `npm install`
4. `.env` file banao
5. `npm start`
